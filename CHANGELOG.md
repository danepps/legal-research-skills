# Changelog

Releases of the `law` plugin for Claude Code and the companion Codex skills. Claude Code users receive a release when the version below changes (`/plugin marketplace update danepps`, or automatically if auto-update is on for the `danepps` marketplace). Codex users re-run the installer.

## 1.0.0 (2026-10-18)

First public release.

- Claude Code: `law` plugin with six skills (legal-research, cite-check, proofread, find-cite, build-library, case-prep), installable from the `danepps` marketplace in this repository.
- Codex: six skills (legal-research-memo, cite-check, internal-proofread, find-cite, build-zotero-library, deep-research), installed by the one-line installer.
